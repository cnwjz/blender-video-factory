# ASSET_CAPABILITY_REQUIREMENTS

## 资产分类总览

资产分为三类：

| 分类 | 说明 | 功能缺失影响 |
|------|------|-------------|
| A. 核心互动资产 | 功能缺失会直接影响剧情表达 | BLOCKER |
| B. 次要互动资产 | 最好支持互动，但不能阻止第一条视频继续 | NICE_TO_HAVE |
| C. 背景资产 | 负责环境可信度，不要求可动 | COSMETIC |

---

## A. 核心互动资产

### 收银台和传送带

| 要求 | 说明 |
|------|------|
| 传送带表面或商品可以表现持续输送 | 通过 UV 滚动、材质动画或关键帧实现均可 |
| 中间窗口关闭时可以停止 | 中间传送带必须独立可控 |
| 左右传送带可以继续运行 | 三条传送带必须独立可控 |
| 传送带、台体和其他部件应能够独立控制 | 部件分离是 EASY_TO_RIG 的前提 |

### 窗口指示灯

| 要求 | 说明 |
|------|------|
| 绿色工作状态 | 发射材质、灯光或独立对象均可 |
| 红色关闭状态 | 与绿色状态使用同一机制切换 |
| 可以通过材质、灯光或独立对象稳定切换 | 不需要物理灯光；材质 Emission 强度切换可接受 |

### 卷帘或关闭牌

| 要求 | 说明 |
|------|------|
| 下降、翻转、滑动或显现 | 任一机制均可 |
| 打开和关闭状态必须清晰 | 两个状态之间的视觉差异必须一眼可辨 |
| 活动部件必须独立，或容易拆分 | 独立对象或独立网格部分是前提 |

### 收银员人物

| 要求 | 说明 |
|------|------|
| 站立工作 | 基础站立姿态 |
| 停止操作 | 手部从工作位置放下 |
| 转身 | 身体旋转约 90–180 度 |
| 行走离开 | 从收银位置走开 |
| 人物需要可用骨骼，或具有足够清晰的可动画层级 | Rigify、Auto-Rig Pro 或清晰的父子层级均可 |

### 顾客人物（至少 3 名：M1、M2、M3）

| 要求 | 说明 |
|------|------|
| 站立排队 | 基础站立姿态 |
| 缓慢前进 | 小步幅前进动画或关键帧 |
| 停下 | 从行走到静止的过渡 |
| 头部或身体转向 | 看向左右窗口 |
| 完整转身 | 身体旋转约 90–180 度 |
| 行走 | 步行动画或关键帧位移 |
| 重新加入队伍 | 走到新队伍末尾并恢复排队姿态 |

### 商品

| 要求 | 说明 |
|------|------|
| 随传送带移动 | 跟随传送带表面或沿传送带方向位移 |
| 窗口关闭后停止 | 中间传送带停止时商品同步停止 |
| 不要求每件商品具有复杂独立动画 | 批量跟随传送带运动即可 |

---

## B. 次要互动资产

| 资产 | 最低要求 | QUALITY（非阻断） |
|------|---------|-------------------|
| 购物篮 | 至少能够稳定跟随顾客（父子关系或约束） | 手柄摆动、内部商品可见 |
| 购物车 | 至少能够稳定跟随顾客 | 车轮真实旋转、把手细节 |
| 扫码枪 | 位置可见于收银台区域 | 手持动画、光束效果 |
| 扫描器 | 闪光或颜色变化（材质切换）优先于复杂手持扫描动作 | 激光扫描线、音效同步 |
| 购物袋 | 存在于收银区域即可 | 装袋动画、物理模拟 |
| 收银屏幕 | 只需支持简单内容切换（静态图片切换） | 实时金额计算、动态 UI |

---

## C. 背景资产

以下资产主要负责环境可信度，不要求可动：

- 货架
- 远处商品
- 墙面
- 地面
- 广告牌
- 天花板灯具
- 背景装饰

**不得因为背景资产缺少动画而判定不可用。**

## 能力分类标准

每个候选资产审核后必须标记为以下四类之一：

| 分类 | 定义 |
|------|------|
| READY | 已经支持所需动作，可以直接使用 |
| EASY_TO_RIG | 没有现成动画，但活动部件独立，只需设置原点、父子关系或关键帧 |
| REQUIRES_MODIFICATION | 需要拆模、补建内部结构、修复骨骼、修正材质或重新组织层级 |
| UNSUITABLE | 功能实现成本过高，或者无法稳定用于当前剧情，应更换资产 |

---

## 资产审核字段

以后审核每个候选资产时填写以下字段：

| 字段 | 说明 |
|------|------|
| ASSET_NAME | 资产名称 |
| ASSET_TYPE | 资产类型（CHARACTER / PROP / DEVICE / ENVIRONMENT） |
| SOURCE | 资产来源（BlenderKit / Sketchfab / 自制 / 其他） |
| LICENSE | 许可类型 |
| COMMERCIAL_USE_ALLOWED | 是否允许商业使用（TRUE / FALSE / UNKNOWN） |
| VISUAL_STYLE_MATCH | 与目标视觉风格的匹配度（1–5） |
| REQUIRED_ACTIONS | 本视频所需的全部动作列表 |
| EXISTING_ANIMATIONS | 已有动画列表 |
| MOVABLE_PARTS | 可独立移动的部件列表 |
| PARTS_SEPARATE | 部件是否已分离为独立对象（TRUE / FALSE / PARTIAL） |
| RIG_AVAILABLE | 骨骼/绑定是否可用（TRUE / FALSE / PARTIAL） |
| ORIGIN_OR_PIVOT_VALID | 原点或轴心点是否合理（TRUE / FALSE / NEEDS_FIX） |
| INTERIOR_GEOMETRY_COMPLETE | 内部几何体是否完整（TRUE / FALSE / N/A） |
| TEXTURES_AVAILABLE | 贴图是否可用（TRUE / FALSE / PARTIAL） |
| SCRIPT_CONTROLLABLE | 是否可通过脚本控制关键属性（TRUE / FALSE / PARTIAL） |
| EXPECTED_MODIFICATION | 预计需要的修改工作 |
| CAPABILITY_CLASS | READY / EASY_TO_RIG / REQUIRES_MODIFICATION / UNSUITABLE |
| BLOCKERS | 阻断使用的具体问题 |
| QUALITY_NOTES | 质量改进建议（非阻断） |
| DECISION | APPROVED / REJECTED / NEEDS_REVIEW |

## 第一段功能样片范围（FROZEN）

### 时长

约 3–5 秒（约 90–150 帧）。

### 验证范围

只验证以下核心互动序列：

1. 传送带运行（三条均可见运行）
2. 中间指示灯由绿变红
3. 中间传送带停止
4. 卷帘下降或关闭牌出现
5. 中间收银员离开
6. 最前方顾客（M1）开始转身

### 不在功能样片范围内

以下内容明确排除，不得作为功能样片的阻断条件：

- 完整 M1/M2/M3 分流（仅验证 M1 转身）
- 完整 345 帧动画
- 钱箱打开
- 付款
- 装袋
- 实时金额变化
- 复杂面部表情
- 购物车轮子真实转动
- 正式音效和字幕
- 最终 1080×1920 渲染（功能样片可使用低分辨率预览）
