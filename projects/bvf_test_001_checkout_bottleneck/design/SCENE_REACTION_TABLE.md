# SCENE_REACTION_TABLE

## 视频基础规格

| 项目 | 规格 |
|------|------|
| 平台 | 抖音 |
| 画幅 | 9:16 |
| 目标分辨率 | 1080×1920 |
| 目标帧率 | 30 FPS |
| 暂定时长 | 约 11.5 秒（约 345 帧） |
| 表现路线 | Blender 三维动画 + 剪映或 Remotion 包装 |

---

## Segment 1：第一秒钩子

| 字段 | 内容 |
|------|------|
| TIME_RANGE | 0.0–1.2 秒（帧 0–36） |
| STORY_PURPOSE | 让观众马上看清三个收银窗口和三条队伍，并产生"少一个窗口会发生什么"的兴趣 |
| HUMAN_ACTIONS | 顾客正常排队；收银员正在工作；队伍有轻微向前移动 |
| DEVICE_REACTIONS | 三个窗口指示灯为绿色；三条传送带正常运行；商品缓慢向扫描区移动；扫描器有轻微工作反馈 |
| PROP_REACTIONS | 商品随传送带移动；购物篮/购物车随顾客静止或微动 |
| CAMERA_FOCUS | 中远景，同时展示三个收银窗口和三条队伍的全貌 |
| POST_PRODUCTION | 标题建议："少开一个窗口，为什么队伍突然变长？"；必须给抖音右侧按钮、顶部标题和底部文字保留安全区 |
| BLOCKER_IF_MISSING | 三个窗口和三条队伍必须同时可见；指示灯状态必须可区分 |

---

## Segment 2：正常运转

| 字段 | 内容 |
|------|------|
| TIME_RANGE | 1.2–3.2 秒（帧 36–96） |
| STORY_PURPOSE | 先让观众理解系统原本正常运行 |
| HUMAN_ACTIONS | 三条队伍缓慢前进；收银员持续工作 |
| DEVICE_REACTIONS | 传送带持续运行；商品持续移动；扫描器闪光或改变颜色；三个窗口保持绿色工作状态 |
| PROP_REACTIONS | 商品持续向扫描区移动；购物篮/购物车随顾客前进 |
| CAMERA_FOCUS | 维持中远景，可轻微推进以建立空间感 |
| POST_PRODUCTION | 可使用轻微箭头或高亮表示队伍向前运动；不得遮挡人物和收银窗口 |
| BLOCKER_IF_MISSING | 三条传送带必须可见运行状态；商品移动方向必须正确（向扫描区） |

---

## Segment 3：中间窗口关闭

| 字段 | 内容 |
|------|------|
| TIME_RANGE | 3.2–5.2 秒（帧 96–156） |
| STORY_PURPOSE | 用清晰的连续反应表现中间窗口停止服务 |
| HUMAN_ACTIONS | 中间收银员停止工作并离开；中间顾客停止前进；最前方顾客看向关闭窗口 |
| DEVICE_REACTIONS | 中间指示灯由绿色变红色；中间传送带停止；中间商品停止移动；卷帘下降，或者明确的关闭牌出现；中间收银区可轻微变暗；左右窗口继续正常工作 |
| PROP_REACTIONS | 中间传送带上的商品停止移动；左右传送带商品继续移动 |
| CAMERA_FOCUS | 聚焦中间窗口，展示关闭过程的完整序列；然后拉远展示左右窗口仍在工作 |
| POST_PRODUCTION | 关闭提示音；中间窗口短暂高亮；可出现"暂停服务"文字 |
| BLOCKER_IF_MISSING | 中间指示灯必须从绿色变为红色；中间传送带必须可见停止；左右窗口必须继续运行 |

---

## Segment 4：顾客分流

| 字段 | 内容 |
|------|------|
| TIME_RANGE | 5.2–9.5 秒（帧 156–285） |
| STORY_PURPOSE | 清楚表现中间队伍被迫加入左右队伍 |
| HUMAN_ACTIONS | M1、M2、M3 依次反应，不得同时开始。动作顺序：先停下 → 头部或身体看向左右 → 转身 → 开始移动 → 加入左右队伍 → 恢复排队状态。购物篮或购物车必须跟随对应顾客。左右队伍继续缓慢前进，并接纳分流顾客 |
| DEVICE_REACTIONS | 中间窗口持续关闭；中间传送带持续停止；左右窗口和传送带继续运行 |
| PROP_REACTIONS | 中间购物篮/购物车随顾客转向并移动至左右队伍；左右传送带商品持续移动 |
| CAMERA_FOCUS | 先展示中间队伍停滞后顾客的犹豫反应；随 M1 移动跟拍至左侧或右侧队伍；最后回到中远景展示分流后三条队伍的新状态 |
| POST_PRODUCTION | 可使用左右方向箭头辅助分流说明；不得让箭头代替人物真实转向和移动 |
| BLOCKER_IF_MISSING | M1、M2、M3 必须依次而非同时反应；顾客转身和移动必须可见；购物篮/购物车必须跟随顾客 |

---

## Segment 5：结果展示

| 字段 | 内容 |
|------|------|
| TIME_RANGE | 9.5–11.5 秒（帧 285–345） |
| STORY_PURPOSE | 让观众一眼看懂服务窗口减少后，剩余队伍变长 |
| HUMAN_ACTIONS | 所有顾客进入最终排队状态；左右队伍明显比开头更长；新顾客可继续进入，使拥堵结果更明显 |
| DEVICE_REACTIONS | 中间窗口保持关闭；左右窗口继续工作；中间区域与左右工作区域形成明显状态对比 |
| PROP_REACTIONS | 商品在左右传送带继续移动；中间传送带商品静止 |
| CAMERA_FOCUS | 中远景静态镜头，同时展示三个窗口和三条队伍的前后对比；最后一帧应当可以单独作为总结画面或封面候选 |
| POST_PRODUCTION | 结论文字建议："顾客没有减少" / "但服务窗口变少了" / "拥堵自然集中到剩余队伍" |
| BLOCKER_IF_MISSING | 左右队伍必须明显比 Segment 1 更长；中间窗口关闭状态必须与左右工作状态形成对比 |
